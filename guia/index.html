Em resumo

O CC Dashboard é um kit em português para usar os Dashboards do Claude, painéis que guardam as consultas e refazem as contas sempre que você abre. Serve para donos de pequenos negócios e para quem usa o Claude Code todo dia. Ele traz prompts prontos para montar painéis do negócio (dinheiro, atrasos, vazamentos) e um plano para medir o próprio Claude Code (custo estimado, ferramentas, falhas). Para usar, você precisa de um plano pago do Claude e, nas partes com banco de dados, de uma conta gratuita no Supabase.

O que é

Painel que guarda a pergunta, não só a resposta

Um painel antigo era uma foto tirada uma vez. O Dashboard do Claude guarda as consultas e roda de novo nos seus dados toda vez que é aberto.

💼 Painel do negócio

Onde está o dinheiro, o que está atrasado, onde você perde receita. Começa com um app e cresce para uma base central que cruza vários.

🔭 Painel do Claude Code

Sessões, tokens, cache, custo estimado, ferramentas e servidores MCP que mais falham, skills mais usadas e a saúde do coletor.

🔍 Número conferível

Cada cartão mostra a consulta e a hora da última atualização. O kit ensina a ler a consulta e a conferir um número na origem antes de agir.

Como funciona

Dois caminhos, o mesmo princípio

O painel só mostra o que o Claude consegue ler. No negócio, a leitura vem dos conectores; no Claude Code, vem da telemetria que ele mesmo envia.

Negócio

Apps (CRM, planilha, banco)→ Conector no Claude→ Base central no Supabase (quando cruza apps)→ Dashboard→ Cópia agendada

Claude Code

Claude Code (OpenTelemetry)→ Coletor no Supabase (filtra campos)→ Tabelas brutas (7 dias)→ Resumo diário (a cada 10 min)→ Dashboard

🔒 O que o coletor guarda

Nome do modelo, da ferramenta, da skill e do servidor MCP, contagem de tokens, custo estimado, duração, sucesso ou falha, tipo de erro e nome da máquina.

🗑️ O que ele joga fora

Texto dos prompts e das respostas, comandos completos, caminhos de arquivos, entradas e saídas de ferramentas, texto de erro e e-mail. Do shell fica só o nome do programa.

⏱️ Quatro relógios

O Claude Code envia a cada poucos segundos, o resumo recalcula a cada 10 min, o painel refaz as consultas ao abrir, e os outros apps só estão tão novos quanto a última cópia.

Pré-requisitos

O que você precisa ter

O recurso está em beta e conta no uso do seu plano.

Plano pago do Claude

Pro, Max, Team ou Enterprise. No Enterprise, um administrador liga os Dashboards nas configurações da organização, em Artifacts.

Conta no Supabase

Grátis para começar (500 MB). Projeto gratuito pausa após uma semana sem uso. Só é preciso nas fases com base central e no painel do Claude Code.

Claude Code

Só para o painel de observabilidade. As variáveis valem para Mac, Linux e Windows; teste no seu sistema antes de confiar.

# onde vai a configuração
~/.claude/settings.json
Guia de uso · passo a passo

Do primeiro painel ao painel do Claude Code

Os prompts estão na pasta prompts/ do repositório. Copie, troque o que está entre colchetes e cole num chat do Claude.

1

Ligue o conector

Em Customize → Connectors, adicione o app onde está a resposta. Para Supabase só leitura e restrito a um projeto, use um conector personalizado com este endereço:

https://mcp.supabase.com/mcp?project_ref=SEU_PROJECT_REF&read_only=true
2

Peça o painel dizendo o que quer saber

"Quais faturas estão atrasadas e há quanto tempo?" rende mais que "um gráfico de faturas". Dê as definições e proíba alterar dados. Modelo completo em prompts/01-dashboard-negocio.md.

Monte um Dashboard do Claude usando minha conexão com [app].
Pergunta: [o que muda o que eu faço amanhã].
Definições: [saldo = total − pago; pago vazio = 0].
# Use consultas salvas, não altere dados, pergunte se faltar algo.
3

Confira um número antes de agir

Clique no número e leia a consulta: data de referência, quais registros entram, se desconta pagamentos parciais e onde ficam as bordas das faixas. Depois compare um número com o app de origem (prompts/02-conferir-numero.md).

# a consulta mostra como foi calculado — não garante que está certo
4

Cruze apps numa base central

Horas × faturas, assinaturas × cobranças, lucro × dinheiro no banco: isso exige copiar os registros para o Supabase. Comece com uma pergunta, duas tabelas e um piloto de 90 dias (prompts/03-base-central.md).

Quero responder: que trabalho foi entregue e nunca faturado?
# o Claude propõe o schema e o piloto e espera seu OK
5

Agende a atualização

Sem cópia agendada, o painel lê dados velhos. Peça uma tarefa diária ou semanal e um cartão "Última atualização" (prompts/05-agendar-atualizacao.md).

Crie uma tarefa agendada que, todo dia às 6h, recopie [app] para o schema [nome].
6

Monte o painel do Claude Code

Com o conector Supabase com escrita (só para a montagem), cole prompts/04-observabilidade-claude-code.md num chat novo. O Claude pergunta o projeto, o fuso e o nome da máquina, lista os passos e espera o seu OK.

# cria: schema cc_obs, função cc-coletor, resumo a cada 10 min, limpeza diária
7

Ligue a telemetria e reinicie

Cole o bloco env em ~/.claude/settings.json (modelo em config/claude-code-otel.example.json). Feche o Claude Code por completo e abra de novo: ele só lê essas variáveis na partida.

{ "env": {
  "CLAUDE_CODE_ENABLE_TELEMETRY": "1",
  "OTEL_EXPORTER_OTLP_PROTOCOL": "http/json",
  "OTEL_EXPORTER_OTLP_LOGS_ENDPOINT": "https://<ref>.supabase.co/functions/v1/cc-coletor/v1/logs",
  "OTEL_EXPORTER_OTLP_HEADERS": "x-cc-key=<chave>",
  … (bloco completo no arquivo de exemplo)
} }
8

Teste e abra o painel

Numa sessão nova, mande um prompt simples e avise o Claude no chat. Ele confere se o coletor recebeu e monta as cinco abas. Dê um dia de uso antes de julgar os gráficos.

claude --debug-file /tmp/cc.log  # se nada chegar, procure linhas [3P telemetry]
Exemplos

Perguntas que viram painel

O que funciona bem: uma pergunta que muda uma decisão, com definição clara.

💰 Faturas em atraso

Saldo em aberto por faixa (a vencer, 1–30, 31–60, 61–90, 90+ dias), por cliente, com a data de referência explícita.

🧾 Trabalho não faturado

Horas registradas que não aparecem em nenhuma linha de fatura — exige base central com as duas fontes.

🏦 Lucro × caixa

Resultado contábil do mês contra o dinheiro que de fato entrou e saiu do banco.

🛠️ Ferramenta que mais falha

Chamadas, % de falha e duração p50/p95 por ferramenta e por servidor MCP nos últimos 7 dias.

🧠 Cache que não pega

Tokens de cache lidos contra criados por dia — cache sendo reconstruído toda hora aparece aqui.

🧩 Custo por skill

Uso e custo estimado por skill e por tipo de subagente, para saber o que vale a pena manter.

Antes de confiar

Limites que você precisa saber

Mostra, não avisa

O painel não manda alerta. Para aviso quando um número passa do limite, crie uma rotina agendada separada.

Custo é estimativa

O valor é o que o uso custaria em preço de API. Em Pro ou Max, a conta é a assinatura.

Cada pessoa com sua conexão

Quem recebe o painel precisa de acesso próprio ao mesmo projeto Supabase; sem isso os cartões ficam vazios.

Nomes também contam

Nomes de skills, repositórios e servidores MCP ficam guardados. Pense em quem vai ver.

Só o Claude Code

O chat do app e o Cowork não entram nesse painel de observabilidade.

Espaço no banco

500 MB no plano grátis. Os brutos ficam 7 dias, o resumo fica para sempre. Vigie o cartão de tamanho.

Fases para construir o sistema

O plano completo está em PLANO.md. Ordem sugerida: primeiro o painel do Claude Code (uma tarde), depois o do negócio.

B0–B1
Projeto e bancoSchema cc_obs, filtro por lista de campos permitidos, resumo diário, limpeza de 7 dias, papel só leitura.
B2–B3
Coletor e telemetriaFunção cc-coletor com chave por máquina; bloco env no Claude Code; reiniciar e testar.
B4
Painel de cinco abasVisão geral, gasto e cache, ferramentas e MCP, skills e subagentes, saúde do coletor.
A1–A2
Painel do negócio direto do appPergunta + definições + conferência de um número na origem.
A3–A4
Base central e cópia agendadaUma pergunta que cruza dois apps, piloto de 90 dias, atualização diária ou semanal.
A5
Diagnóstico e acompanhamentoVarredura só leitura, problemas que se somam, plano priorizado e, com o seu sim, um painel que marca cada item como feito.
B5–B7
Mais máquinas, histórico e alertasUma chave por máquina, importação do histórico local de sessões e avisos por mensagem.
